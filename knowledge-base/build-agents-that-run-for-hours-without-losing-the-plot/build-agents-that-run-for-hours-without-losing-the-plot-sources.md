# Sources

**Talk:** Build Agents That Run for Hours (Without Losing the Plot)

**Speakers:** Ash Prabaker and Andrew Wilson, Anthropic

**Event:** AI Engineer World's Fair 2026, San Francisco

**Published:** 18 May 2026

Official recording: https://www.youtube.com/watch?v=mR-WAvEPRwE

## What the talk covers

Why self-evaluation is a trap and adversarial evaluator agents work better. Why context compaction does not cure coherence drift but structured handoffs do. How to decompose work into testable sprint contracts. How to grade subjective output with rubrics an LLM can actually apply. How to read traces as the primary debugging loop. And which parts of a harness to delete when the next model drops.
