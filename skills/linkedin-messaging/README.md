# LinkedIn Messaging

**Type** Cowork skill  ·  **Trigger** Any message, connection note or introduction request written as the principal on LinkedIn

## What it does

Owns the copy, register, structure and send protocol for messages written in the principal's name on LinkedIn. Browser mechanics live in [browser-operation](../browser-operation/README.md), this skill owns what gets said and how it ships. Built from real sent messages and the corrections made to them, the worked examples carry the lessons.

## Flow

```
message request, written as the principal
   |
pre-draft checks ── conflict pass, prior contact,
   |                the actual local clock
draft ── calibrated salutation, one idea per
   |     paragraph, weakest claim last,
   |     open-door close
compose in the browser ──> screenshot
   |
show the rendered message ──> wait for the explicit yes
   |
paid credit involved? surfaced before anything ships
   |
send
```

## How it runs

The send protocol is absolute. Compose, screenshot, show the rendered message, wait for an explicit yes, even when the instruction was to send. Costs are surfaced before sending, a paid message credit is the principal's to spend, not the agent's. Greetings are computed, never guessed, the time-of-day salutation is checked against the actual local clock because a morning greeting landing at night is the cheapest possible way to look automated. The message shape is fixed, a relationship-calibrated salutation, short paragraphs with one idea each, achievement over biography in the body, the weakest claim placed last where it interrupts nothing, and a close that leaves a door open.

Favour asks are a different shape, the reason before the request, the smallest possible ask, an explicit exit so the reader never feels cornered, and no two identical asks ever sent, varied in register and length so parallel recipients never compare notes on a template.

## Guardrails

Counterparty partners and their clients are never named, and the pre-draft checks include a conflict-of-interest pass before a single word is written. No connection request rides alongside an application, it reads intrusive. No flattery about the target company, researched-at is a register people smell. Language follows the reader, not the firm.

## Lessons carried

Two live corrections shaped the copy rules. A dead brand name was cut from an achievement sentence because the achievement carries the proof and the brand spent a clause buying nothing. An under-hedged claim was strengthened on the principal's own instruction, on a claim you want to land, blandness is the failure, not modesty. And the intermediary check exists because a shared-connection indicator proved nothing, a weak-link introduction request spends relationship capital and buys nothing.
